# YouTube ASO Research Tool

Bir anahtar kelime için YouTube'da rekabet analizi yapar: rakip videoların izlenme sayıları, aylık izlenme ortalaması, Google Trends skoru ve fırsat puanı hesaplanır. Böylece o konuda video yapmanın mantıklı olup olmadığına karar vermek kolaylaşır.

## Kullanım

```bash
pip install -r requirements.txt
python aso_research.py "anahtar kelime"
python aso_research.py "anahtar kelime" --cookies-from-browser chrome
python aso_research.py "anahtar kelime" --demo
```
